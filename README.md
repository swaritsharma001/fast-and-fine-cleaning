# Shamsa Laundry – Dubai Branch

A modern, responsive, luxury single-page website for **Shamsa Laundry – Dubai Branch**, featuring deep black backgrounds (`#0A0A0A` / `#121212`), pure white text, and gold accents (`#D4AF37`, `#F1D77A`), Playfair Display serif headings, Poppins body typography, smooth sliders, live Dubai operating hours, and official brand integrations.

## 🚀 How to Deploy to Vercel

This repository is already configured with `vercel.json` for zero-config Vercel deployment.

### Option 1: Deploy with Git (Recommended)
1. Push this repository to GitHub, GitLab, or Bitbucket:
   ```bash
   git add .
   git commit -m "Initial commit of Shamsa Laundry Dubai website"
   git branch -M main
   git remote add origin <your-github-repo-url>
   git push -u origin main
   ```
2. Log in to [Vercel](https://vercel.com).
3. Click **"Add New..."** → **"Project"**.
4. Import your GitHub repository.
5. Vercel will automatically detect **Vite**:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
6. Click **Deploy**. Your site will be live within seconds with HTTPS and custom domain support!

### Option 2: Deploy using Vercel CLI
1. Install the Vercel CLI globally (if not already installed):
   ```bash
   npm i -g vercel
   ```
2. Run deploy in the project root:
   ```bash
   vercel
   ```
3. To deploy directly to production:
   ```bash
   vercel --prod
   ```
